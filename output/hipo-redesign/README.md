# HIPO 사용자 경험 리디자인

2026-09-23 기준, 첫 진입부터 핵심 탭까지 하나의 브랜드 경험으로 다시 설계했습니다.

## 브랜드 방향

- 핵심 문장: **사람의 가능성을 발견하고, 응원하고, 함께 성장하는 마켓**
- 첫 화면 카피: **좋아하는 사람의 다음을 먼저 만나요**
- 숫자와 거래를 앞세우기보다 사람·발견·응원을 먼저 설명합니다.
- PO와 사람 주식이 실제 금융상품이 아니라는 안내를 첫 화면과 홈에 배치했습니다.
- 색상은 코발트 블루 `#2F6BFF`, 딥 잉크 `#172640`, 라일락, 작은 코랄 포인트로 통일했습니다.
- 이모지 버튼과 검은색 탭 바를 제거하고 Ionicons, 14~27px 라운드, 밝은 중성 배경을 일관되게 사용합니다.

## 구현 화면

- 비회원 첫 진입 히어로
- 로그인 및 회원가입
- 게스트/회원 홈
- 사람 발견 마켓
- 커뮤니티 피드
- 내 HIPO 및 게스트 전환 화면
- 지갑, PO 전환·환전 바텀시트, 거래 흐름 목록
- PO 보내기 화면의 헤더·잔액·입력·버튼 스타일
- 4개 탭 하단 내비게이션과 로딩 화면
- 앱 아이콘, 스플래시, 웹 파비콘
- 전역 기본 색상과 배경 토큰

기존 거래·송금·포트폴리오·설정 화면으로 이어지는 경로는 유지했습니다.

## 생성 이미지

OpenAI 내장 `image_gen`으로 생성한 뒤 프로젝트에 저장했습니다.

- `frontend/assets/brand/welcome-people.png`: 첫 진입 사람 연결 일러스트
- `frontend/assets/brand/home-discovery.png`: 홈 발견 히어로 배너
- `frontend/assets/brand/growth-steps.png`: 성장·자산 카드 일러스트
- `frontend/assets/brand/app-icon-v2.png`: 새 앱 아이콘

공통 프롬프트 방향은 부드러운 3D 에디토리얼, 코발트·페리윙클·아이보리·코랄, 텍스트·로고·워터마크 금지입니다. 앱 아이콘은 사람 두 명과 상승 연결을 추상화한 독립 심볼로 만들었습니다.

## 생성 프롬프트 요약

1. 사람 연결: 다양한 세 사람과 반투명 연결 카드, 투명 배경, 부드러운 3D.
2. 홈 발견: 무대 위 크리에이터와 떠오르는 프로필 카드, 왼쪽 카피 여백이 있는 가로 배너.
3. 성장: 계단형 플랫폼을 오르는 인물과 빛나는 씨앗, 투명 배경.
4. 앱 아이콘: 두 사람과 상승 연결을 추상화한 단일 심볼, 코발트 바탕과 흰색 형태.

실제 운영 API 응답과 로그인 후 데이터가 채워진 상태의 내용 밀도는 운영 또는 스테이징 서버에서 한 차례 더 확인하는 것이 좋습니다.
